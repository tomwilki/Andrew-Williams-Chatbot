# Andrew Williams Hair & Beauty - chatbot deployment

Same process as before:
1. Upload this folder to a new GitHub repo (e.g. `andrew-williams-chatbot`)
2. Connect to Vercel, import the repo, deploy
3. Add your ANTHROPIC_API_KEY environment variable in Vercel settings, redeploy
4. Copy your live Vercel URL, paste it into BACKEND_URL inside widget-embed.html
5. Give widget-embed.html to the salon (or their web developer) to paste into their website,
   just before the closing </body> tag

Facts used in this chatbot were sourced from the salon's public website and Google listing.
Double check hours, services and the Fresha booking link with the salon directly before going live,
business details can change.
